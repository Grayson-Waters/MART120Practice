The CLI can be very intimidating at times because of how many options one has. Since your choices are not listed out right in front of you with drop downs, images, and even a basic starting point, it can be hard to understand where to start and what you can do. I like the command line interface, although I would not consider myself to be proficient yet. I think that when one does learn how to efficiently use the command line it is very efficient. I have noticed slowdowns when I click options like new folder and renaming it in the GUI. I like the GUI for its simplicity. I know how to do almost everything that I need to do in it because it is very similar to most software and web apps that we use today. It has tabs, drop downs, for certain options, and one can access everything by clicking around. In the GUI the mouse is all you need, while in the CLI the mouse does next to nothing except for highlighting.
